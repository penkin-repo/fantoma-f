# Fantoma F

Легковесный менеджер временной активации шрифтов для Windows (Go + Wails v2 + React).

Позволяет просматривать коллекции `.ttf` / `.otf` и временно подключать шрифты для Adobe Illustrator, Photoshop, Figma и других программ **без постоянной системной установки** и прав администратора.

## Возможности

- **Временная активация без «фантомных» шрифтов**:
  - Уникальные хешированные имена файлов при стейджинге (`<fnv32>_<filename>`), исключающие коллизии одноимённых шрифтов (`Regular.ttf`) из разных папок.
  - Чистый HKCU per-user реестр + параллельное копирование + один асинхронный `PostMessageW(WM_FONTCHANGE)` (без медленных GDI `AddFontResourceW`/`RemoveFontResourceW`, чтобы сотни шрифтов включались и выключались за секунды).
  - Вытеснение заблокированных файлов (если Illustrator держит открытый файл при деактивации) из `Windows\Fonts\fantomaf` в `LOCALAPPDATA\FantomaF\trash` с очисткой при следующем запуске.
  - Перехват `WM_ENDSESSION` при выключении/перезагрузке Windows — шрифты чисто выгружаются из системы, но список `activeFonts` в `config.json` сохраняется и автоматически восстанавливается при следующем запуске (настраивается в Settings).
- **Интерфейс**:
  - Тёмная тема **Obsidian Dark** (по умолчанию) и светлая **Warm Paper** с синхронизацией системного заголовка окна Windows.
  - Векторные иконки (`lucide-react`), виртуализированный список шрифтов, раскрытие отдельных начертаний семейства.
  - Фильтрация по типу (OS/2 + PANOSE + `post.isFixedPitch`), насыщенности, курсиву и активным шрифтам; ручное переопределение категории.
  - Автоотслеживание изменений в папках (`fsnotify`), системный трей с быстрой деактивацией и автозапуск Windows.

## Разработка и сборка

Требования: Go 1.24+, Node.js 18+, `pnpm`, Wails CLI v2.

```sh
# Режим разработки с hot-reload
wails dev

# Продакшен-сборка (результат: build/bin/FantomaF.exe)
wails build
```

Конфигурация (`config.json`) хранится рядом с исполняемым файлом `FantomaF.exe`.
